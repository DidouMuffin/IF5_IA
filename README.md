# IF5 — Détection de défauts industriels

Projet MATLAB de BUT GEII consacré à la détection et à la classification de défauts sur des images industrielles.

## Organisation prévue

- À la racine, le Live Script MATLAB (`.mlx`) du projet.
- `src/` pour les fonctions MATLAB et le code de l’interface.
- `data/train/` pour les images, avec un sous-dossier par classe de défaut.
- `docs/` pour les consignes et le rapport, selon les fichiers disponibles.

## Utilisation

Ouvrir la racine du projet comme dossier courant dans MATLAB. Placer les images dans `data/train/`, puis ouvrir le Live Script et exécuter les sections dans l’ordre.

Le jeu d’apprentissage du projet comporte six classes de défauts et 240 images par classe, soit 1 440 images.
